# Data Directory

This directory contains sample input templates, benchmark prompt examples, and evaluation datasets used to demonstrate the Natural Language Generator.

## Example Benchmark Inputs

1. **Department Statistics (Structured Data -> Text)**
   - Input:
     ```text
     Department: Computer Science
     Students: 120
     Average Attendance: 91%
     Pass Percentage: 94%
     Top Subject: Data Structures
     ```

2. **Corporate Financial Summary (Data Summary -> Report)**
   - Input:
     ```text
     Revenue: ₹12.5M
     Growth: 18%
     Customers: 24,500
     Churn: 4.2%
     ```

3. **Academic Overview (Prompt -> Text)**
   - Input:
     `Write a short formal description of a university computer science department.`
